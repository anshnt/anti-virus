What this app does

  • Uses the installed Microsoft Defender engine for scans and signature updates.
  • Reads security status, scan events, startup entries and TCP connections.
  • Checks local files for signatures, hashes and a small set of script patterns.
  • Monitors Downloads and selected file baselines while running.
  • Stores evidence on this PC. The console does not upload samples.

What it cannot promise

No commercial certification, independent malware engine, kernel sensor, ransomware rollback or guarantee that all malware is detected. Defender’s existing Microsoft cloud and sample submission settings still apply.

Some Windows evidence needs administrator permissions. Missing checks are shown as unavailable. This app does not bypass Windows permissions.
