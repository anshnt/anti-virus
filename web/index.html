REVERSIBLE REMEDIATION

Encrypted quarantine

Files moved here are encrypted for your Windows account using DPAPI.

Quarantine removes the verified original only after an encrypted copy and recovery record exist. Recovery writes a separate .restored copy in the app's private recovery folder. It never overwrites an original or automatically runs a recovered file.

What this app does

  • Runs its independent ClamAV engine and official signature updates.
  • Provides encrypted, hash-verified quarantine and separate recovery copies.
  • Queues changed Downloads for independent scans while running.
  • Reads Windows security, startup and TCP evidence, with optional Defender scans.
  • Stores evidence on this PC without uploading samples.

What remains unproven

This development build has no independent comparative malware benchmark, certified Windows kernel blocker, ransomware rollback or tamper-resistant system service. It has not been shown to outperform Defender. Windows cloud and sample submission policies still apply to Defender.

Some Windows evidence needs administrator permissions. Missing checks are shown as unavailable. The app does not bypass permissions.
